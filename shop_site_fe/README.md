# Decorem frontend

This React application is built with Vite and runs on port 3000 by default.

## Available scripts

### `npm run dev`

Starts the Vite development server at <http://localhost:3000>.

### `npm test`

Runs the Vitest test runner.

### `npm run build`

Builds the production frontend into the `dist` directory.

### `npm run preview`

Serves the production build locally for verification.

## Environment

Create a `.env` file when the API is not running at the default address:

```dotenv
VITE_API_BASE_URL=http://localhost:5000
```
